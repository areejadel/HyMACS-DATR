لماذا تبديل حَكَمَين ليس ضعفاً بل قوّة: القسم **R** في التقرير يقيس هل تبقى نتائج v5 (ترتيب النماذج، إشارة أثر كل شرط) كما هي بلوحة مختلفة الإصدار ⇒ «النتائج لا تعتمد على إصدار حَكَم بعينه». يجب ذكر التبديل صراحة في المنهجية.

## حارس الرصيد (يوقف كل شيء عند أي خلل)

كل استدعاء لأي نموذج يمرّ عبر `guard.py`، فيتوقّف التشغيل **فوراً** ولا يُرسَل أي استدعاء جديد إذا:
1. فشل **8 استدعاءات متتالية** لنفس النموذج أو المزوّد (رصيد منتهٍ، مفتاح خاطئ، نموذج محذوف، ردود فارغة).
2. تجاوزت نسبة الفشل **30%** من آخر 40 استدعاء.
3. أعاد حَكَمٌ **8 ردود غير صالحة متتالية** (JSON مكسور)، أو أعاد مولّدٌ 8 مراجعات مقطوعة (أقصر من 30% من الأصل) — أي أنه يصرف بلا فائدة.
4. بلغ الصرف التقديري **السقف**: Together ‎$18، OpenAI ‎$30، Anthropic ‎$15، OpenRouter ‎$0.5. لتغييره: `export V6_CAP_TOGETHER=18`
5. أوقفتِه يدوياً: `touch results_v6/STOP` (احذفي الملف قبل المتابعة).

عند التوقّف: السبب يظهر على الشاشة ويُحفظ في `results_v6/STOPPED_REASON.txt`، ولا تُحفظ أي نتيجة ناقصة. أصلحي السبب ثم أعيدي نفس الأمر، فيكمل من حيث توقّف.
الصرف المسجّل يظهر مع كل سطر تقدّم، ويُحفظ تراكمياً في `results_v6/spend_ledger.jsonl`.
وأي تشغيلة في exp1 فشل فيها استدعاء وكيل تُعلَّم خطأً وتُعاد تلقائياً، ولا تدخل التحليل (v5 كان يتجاهل هذا الفشل بصمت).
كل الحسابات مسبقة الدفع (prepaid)، فأقصى ما يمكن صرفه هو ما شحنتِه.

## التشغيل خطوة خطوة

**1. فحص سريع** (أقل من سنت). يجب أن يظهر ✓ أمام كل نموذج:
```bash
python smoke_v6.py --with-local
```
إن فشل نموذج: تحقّقي من المفتاح والرصيد، وأن المعرّف ما زال متاحاً على Together.

**2. تجربة صغيرة لكل سكربت** (دقائق، بضعة سنتات):
```bash
python exp2_rejudge_panel.py --part A --limit 6
python exp1_shared_draft.py --topic backprop --skip-local --limit-jobs 2
python analyze_v6.py
```

**3. التشغيل الكامل:**
```bash
bash run_all.sh judges     # ~2–3 ساعات
bash run_all.sh exp1       # ~12–14 ساعة — اتركيه ليلاً والجهاز موصول بالشاحن
bash run_all.sh analyze
```
- **لو انقطع أي شيء** (إنترنت، رصيد، إغلاق الجهاز): أعيدي نفس الأمر، فيكمل من حيث توقّف ولا يعيد ما تمّ.
- امنعي الجهاز من النوم أثناء exp1: `caffeinate -dims bash run_all.sh exp1`
- السجلات في `logs/`. لمتابعة النموذجين المحليين: `tail -f logs/exp1_local.log`
- النموذجان المحليان (ALLaM ثم Llama-3-8B) هما الأبطأ (~15 ساعة معاً). إن كانت ذاكرة جهازك ≥ 24GB يمكن تشغيلهما في نافذتين متوازيتين.
- عدد الخيوط المتوازية: `WORKERS=8 bash run_all.sh judges` (لو ظهرت أخطاء 429 أنقصيه إلى 4).

**4. (اختياري) ALLaM بدقّة كاملة** على سيرفر GPU (Vast.ai/RunPod بذاكرة ≥ 16GB):
```bash
python exp6_allam_precision.py --topic backprop --backend cuda
python exp6_allam_precision.py --topic normalization --backend cuda
```
